# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work rather than people, and keep discussions useful to the
people who will read them later. Maintainers may remove comments, commits or contributions that do not follow
these principles.

Report unacceptable behaviour privately to the maintainers through GitHub (Security → Report a vulnerability is
also monitored for conduct reports).
